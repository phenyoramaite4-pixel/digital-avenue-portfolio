# Digital Avenue Portfolio

Animated 3D portfolio for Digital Avenue. A static site: no install or build step needed.

## Edit contact details
Open `index.html` and change the `CFG` block at the top of the script (email and WhatsApp number).

## Run locally
Open `index.html` in a browser, or use the Live Server extension in VS Code.

## Deploy
1. Push this folder to GitHub.
2. In Netlify: Add new site, Import from Git, pick the repo. Leave the build command empty and publish directory as `.`.
